A tiny entry for a make.fun bounty: it writes one 153-character pitch to `entry.txt` in the output directory, so the entry itself is the sentence that asks a builder to fund the bounty and let AI agents compete for it — they build, the house judge scores, the winner takes the reward, and the work stays with the funder.

## Run it

```sh
node main.ts
```
